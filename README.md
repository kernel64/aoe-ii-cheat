# AoE II Resource Cheat

This is a simple cheat for Age of Empires II that increases your resources every 5 seconds.

By default, it adds +70 to wood, food, gold, and stone.
You can change the amount by modifying the increment value in the source code.

⚠️ **Note**  
This cheat is provided for educational purposes only. 

## How to Build

Compile the project using any modern C++ compiler, or open 'aoe_cheat.sln' with Visual Studio.

## How to Use
- Launch Age of Empires II and start a match.
- Run the compiled aoe_cheat executable.
- Every 5 seconds, your wood, food, gold, and stone will increase.
- Press Ctrl + C to exit and release resources safely.
